# 既有实验摘要

整理日期：2026-11-12。本文集中保留既有实验的范围、主要结果与结论边界；旧逐次记录、图表、快照和归档代码不再作为仓库文档维护。以下为整理前资料的摘要，未重新运行；后续正式对照以[共同协议](multitask-critic.md)重新建立。

## 早期开发实验

| 实验 | 已有结果 | 能说明什么 |
| --- | --- | --- |
| E0 输入／输出与数值诊断 | 真实样本变换核对与合成全模型数值对照验证范围不同，后者未通过原阈值 | 变换可用不等于整个推理实现等价 |
| E1 Motus Clean 基线 | 22 任务×100 场景，汇总 566/2200 | 旧本地协议下的能力快照，不替代当前指令／后端协议的基线 |
| E2 PACE 权重对照 | 没有可用的完整评测成绩 | 未完成不记为零成功率 |
| E3 执行窗口 | 三任务比较 8／16／32 步，排序随任务变化 | 短执行窗口并非始终更好 |
| E4 短预算离线适配 | 同 100 场景：原始 47、独立策略合计 29、共享策略 29、成功重放 25 | 这次适配未改善总体表现；不能据此证明多任务共享有害，也不是论文完整复现 |
| E5 单任务在线 Flow-SDE＋PPO | 瓶子任务原始 9/20，10／20／100 轮为 7／2／1 | 单任务也会退化，不能只归因于任务间冲突 |
| E6 数值／显存／PPO 诊断 | 瓶子原始 9/20，诊断配置第 5 轮 11/20、第 10 轮 9/20 | 工程问题需要处理；短期改善未维持，多个设置同时变化，原因未隔离 |
| E7 五任务在线共享／独立更新 | 留有单训练种子的开发曲线，未建立可用于新路线的完整确认对照 | 在线实验不能替代固定离线基线；不由不完整评估判断共享优劣 |

这些实验的指令、来源、预算、执行方式和种子不统一，不构成算法排名，也不足以确定 critic 是退化的主要原因。

## RLinf RECAP 工程验证

RoboTwin 两任务 pilot 接通了官方 returns → critic → advantages → CFG 四阶段，critic 与 policy 各训练 500 步；检查点复载和 500→502 步恢复更新完成。

| 四个配对开发场景 | 基础无条件 | 基础 positive | 训练后 positive |
| --- | --- | --- | --- |
| click_bell | 0/2 | 1/2 | 0/2 |
| stack_blocks_two | 0/2 | 1/2 | 1/2 |
| 合计 | 0/4 | 2/4 | 1/4 |

这证明工程链路可运行，没有建立策略收益。该 pilot 使用小数据、普通 Motus SFT 起点和 action-expert 更新；数据来源／场景／结果覆盖的缺口仍见共同协议。

独立 LIBERO 参考已完成原始 π0.5 起点的 1000 步自训 SFT、基线评估和 returns。critic、advantages 与后续 CFG 策略训练尚未运行。官方 few-shot 起始权重未公开，自训初始化不能称为精确复现报告的 48.8%→66.5%；该路线不再占用当前长预算。

## 当前五任务 P0 calibration

已有 Motus checkpoint 在本机两条推理路径各评估 100 回合；每任务 20 场景、无 setup error，100 对可见初态指纹匹配：

| 任务 | 原生 | CFG no_guide |
| --- | --- | --- |
| adjust_bottle | 13/20 | 10/20 |
| click_bell | 7/20 | 8/20 |
| place_container_plate | 17/20 | 10/20 |
| place_empty_cup | 5/20 | 7/20 |
| stack_blocks_two | 1/20 | 2/20 |
| 合计 | 43/100 | 37/100 |

这是本机的 Clean、planner-solvable calibration，场景预训练重合未知，不是 5880 验收或最终测试。可见指纹不等于完整模拟器状态一致；每任务样本少，container 的后端差异需排查。后训练比较必须采用同一推理后端。

## 后续保留的判断

- 多任务 SFT 起点可直接使用；先核对推理与数据，再讨论 critic 方法。
- 旧退化没有隔离容量、曝光、标签、条件提示或优化原因；不据此包装多任务冲突或新方法动机。
- 方法线验证共享梯度／标签能否改变 policy，前置线建立同源 BC、critic 与 RECAP-style 的受控基线。

复用代码仍保留：`scripts/run.py` 为通用官方入口，`scripts/evaluate_multitask.py` 为 P0，`scripts/recap.py` 和 `scripts/recap_official.py` 为独立参考工具。配置分类见[配置索引](../configs/README.md)，现有镜像使用见 [Docker 说明](docker.md)；模型和数据保留在本机忽略目录中。
