# 2026-11-07实验快照

本目录保存当日的轻量实验元数据；[manifest.json](manifest.json)给出快照时间、原始路径、目标路径及逐文件SHA-256。

- E1／E3：评估协议、冻结种子和补跑说明。
- E4：离线经验池清单、作业定义与结果。
- E5／E6：历史计划、配置、源码和适配验收。
- E7：冻结计划、6份训练配置、9份算法源码、资源修复设置与真实恢复验收。
- [five-task-curves.json](five-task-curves.json)：保存时的训练／评估状态；待完成项目不能视为0%。
- [results-summary.csv](results-summary.csv)：各阶段逐任务结果摘要。

这里没有模型、优化器、轨迹、原始示范或凭据。配置保留了原实验机的绝对路径用于审计，迁移机器时需重定位。不要用快照覆盖正在运行的 `.runtime/` 目录；运行中的最新状态以实验机报告为准。
